# Team Obsidian — Knowledge Transfer & Architecture Platform

Enterprise knowledge transfer and architecture mapping platform. Standardizes multi-source ingestion from GitHub, Slack, Notion, Jira, Confluence, Linear, GitLab, and Sentry into a unified semantic graph.

## Architecture Highlights
- Multi-cloud credential isolation & RBAC.
- Tree-sitter powered AST parsing for Python, TypeScript, and Go.
- Nango universal integration gateway for automated token rotation.
- Real-time Sentry telemetry ingestion for error-to-code correlation.
